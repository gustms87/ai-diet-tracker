🍓 옵션 A. 내 라즈베리파이 4로 24시간 무료 서버 운영

  1. 이 프로젝트 폴더에 포함된 docker-compose.yml을 라즈베리파이4에 복사합니다.
  2. docker compose up -d 명령 한 줄이면 24시간 자동 재시작 서버가 켜집니다.
  3. 외부(LTE/5G)에서도 접속하려면 무료 Cloudflare Tunnel (cloudflared) 또는 Tailscale을 연결하면 공유기 포트포워딩 없이도 안전하게 HTTPS 주소로 접속됩니다.

☁️ 옵션 B. 무료 클라우드 서버로 24시간 운영

  1. Render / Fly.io / Koyeb / Oracle Cloud Free Tier 등 무료 클라우드에 프로젝트의 Dockerfile을 그대로 배포할 수 있습니다.
  2. 환경변수에 GEMINI_API_KEY만 넣어두면 어디서든 스마트폰과 PC에서 똑같은 식단표가 실시간 동기화됩니다.
  3. PC에서 기록하던 데이터는 [설정] → [JSON 백업]으로 내려받아 새 서버에 1초 만에 그대로 복원할 수 있습니다.
